# Argentina - Pampa
Developed by the team of **MapBiomas Argentina**.

## About

This repository contains scripts for classifying and filtering the **Pampa** region in Argentina.

We highly recommend reading the [Pampa Algorithm Theoretical Basis Document (ATBD)](https://drive.google.com/file/d/1cTh7AxXFPGujjPNIy8G_t6IZoD1dES8O/view?usp=sharing). This document provides fundamental information about the classification methodology and each processing step.
