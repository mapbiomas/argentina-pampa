# Argentina - Pampa

Developed by the team of **MapBiomas Argentina**.

## About

This repository contains scripts for classifying and filtering the **Pampa** region in Argentina.

We highly recommend reading the [Pampa Algorithm Theoretical Basis Document (ATBD)](https://argentina.mapbiomas.org/wp-content/uploads/sites/12/2026/02/ATBD_Collection_5_PampaArg.pdf). This document provides fundamental information about the classification methodology and each processing step.
